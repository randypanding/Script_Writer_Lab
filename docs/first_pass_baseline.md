# 一过率基线（战役日志实证,2026-08-26）

> 用户定义:门禁既是障碍也是导向,合力体现在**一过率**与**整体修改次数**上。
> 口径:一次 attempt = 一次完整管线跑批;failed = 未产出产物的 attempt。
> 一过率 = (attempts - failed) / attempts。门禁命中 = 失败日志【必须修正】段的规则 ID 频次。

## 判读

1. **门禁的"导向"作用已被实证**:STR-014(13 杀)在机械修复器落地后归零;DLG-006(32 杀)从 8/8 集全灭收敛到个位数毫厘——门禁不是纯成本,它把失败模式逐条变成了修复清单。
2. **杀伤集中度极高**:top-2 门(DLG-006/STR-014)贡献了 88% 的 block 命中。新门禁的加入必须回答"它会不会成为下一个高频杀伤门"——如果是,要么配机械兜底,要么降级为建议级先观察。
3. **第二阶段的度量承诺**:R2(正向契约)/R3(best-of-3)每轮验收除三轴判分外,必须同时报告:新 brief 的一过率 + 相位重试次数(runs.db pass 计数比)——**质量上升不得以一过率崩塌为代价**,这是"门禁形成合力"的硬证据。

## 未来门禁的准入规则(建议,写入 R2)

- 新 block 门必须带:①机械修复器 or ②明确指令通道 + 试运行期(建议级 2 轮,观察命中率 <10% 才升 block);
- 每轮结束更新本表,一过率连续两轮下降 >15% 即触发门禁复审(是不是门太苛/指引不清)。
